# 🌍 EcoBot

Умный экологический бот для автоматизации и удобного управления процессами. Проект разработан для помощи пользователям в решении повседневных эко-задач.

## 🚀 Основные возможности
* Автоматизация рутинных действий.
* Удобное меню настроек (через файлы конфигурации).
* Быстрый запуск в один клик.

## 🛠️ Состав проекта
* `EcoBot56.py` — основной исходный код программы на Python.
* `launch.bat` — скрипт для быстрого запуска бота.
* `setup.bat` — скрипт для автоматической установки необходимых библиотек.
* `настройка.txt` — файл конфигурации для кастомизации бота под ваши нужды.

## 📦 Как запустить проект локально
1. Скачайте файлы проекта к себе на компьютер.
2. Убедитесь, что у вас установлен Python.
3. Запустите файл `setup.bat`, чтобы автоматически установить все нужные зависимости.
4. Откройте файл `настройка.txt` и введите ваши данные (например, токен бота).
5. Запустите бота двойным кликом по файлу `launch.bat`
